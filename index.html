Fishing Bot Setup Guide

LDPlayer + Python on Windows. No coding experience needed.

What it does

The bot loops: it casts, waits for the snap, plays the timing mini game (it clicks when the bobber is inside the yellow zone), closes the reward screen, and casts again. It reads colors on your screen and uses your real mouse, so the game must stay visible.

You need: a Windows PC, LDPlayer with the game open on the fishing screen, Python 3.13, and the file fishing_bot.py.

1Install Python 3.13

Download it from python.org and tick “Add Python to PATH” during setup. Newer versions (like 3.15) may not work with the libraries yet.

2Install the libraries

Press Win + R, type cmd, press Enter, then run:

py -3.13 -m pip install opencv-python numpy pyautogui mss keyboard

Type commands in Command Prompt (it shows C:\>), not in Python or IDLE (they show >>>).

3Put the script in a folder

Save fishing_bot.py as C:\fishing\fishing_bot.py. Open that folder, click the address bar, type cmd and press Enter. Use that Command Prompt for every command below.

4Get LDPlayer ready

Open the game on the fishing screen. After this, don’t move or resize the LDPlayer window, because the bot remembers exact screen positions.

5Calibrate (once)

py -3.13 fishing_bot.py calibrate

For each of the 5 prompts, press Enter, hover your mouse over the spot, and keep still until the 4 second countdown ends:

  1. The big green cast button.
  2. The purple hook button (cast once first so it shows).
  3. The left end of the mini game bar (start a mini game first).
  4. The right end of the same bar. Be quick, the mini game lasts about 30 seconds.
  5. The green part of the claim button, not the white text. Use a fish without a mini game.

To redo one part: calibrate bar, calibrate buttons or calibrate claim.

6Time the fish

Use a stopwatch from casting until the fish snaps. Open config.json in Notepad and add your number, a little lower than you measured:

"wait_after_cast": 7.8,

7Run it

py -3.13 fishing_bot.py

You have 5 seconds to click the LDPlayer window. Watch the first few fish. F8 pauses or resumes, F9 quits, and moving the mouse to the top-left corner of the screen also stops it.

Settings in config.json

reward_screen_delay (1.5)
Seconds to wait before closing the reward screen after a mini game. Raise it if it clicks too early.
latency (0.06)
How early the bot taps. Raise it if taps land late, lower it if they land early.
zone_margin (0.25)
How close to the middle of the yellow zone the bobber must be. Higher is pickier.
tap_cooldown (0.45)
Seconds to wait after each tap before reading the new yellow zone.

Troubleshooting

“No config.json found”
Run the calibrate command first.
“No module named …”
The libraries are missing, or you typed in the wrong window. Repeat step 2.
“Region has zero or negative size”
The bar ends were saved in the wrong order. Run calibrate bar.
It never notices the mini game
Start a mini game and run py -3.13 fishing_bot.py debug. If it shows bobber=None, recalibrate the bar.
Black or wrong colors
In LDPlayer settings, switch the graphics renderer between DirectX and OpenGL.
It clicks the wrong places
The window was moved or resized. Put it back or calibrate again.

The bot uses your real mouse, so you can’t use the computer for other things while it runs. Keep the LDPlayer window fully visible. Bots and macros can break a game’s rules and put your account at risk, so use this at your own risk.

Hướng dẫn cài đặt Bot câu cá

LDPlayer + Python trên Windows. Không cần biết lập trình.

Bot làm gì

Bot chạy theo vòng lặp: quăng cần, chờ cá cắn, chơi minigame canh thời điểm (bấm khi phao nằm trong vùng vàng), đóng màn hình phần thưởng rồi quăng tiếp. Bot đọc màu trên màn hình và dùng chuột thật, nên game phải luôn hiển thị.

Bạn cần: máy Windows, LDPlayer đã mở game ở màn hình câu cá, Python 3.13 và file fishing_bot.py.

1Cài Python 3.13

Tải từ python.org và tick vào “Add Python to PATH” khi cài. Bản quá mới (như 3.15) có thể chưa dùng được với các thư viện.

2Cài thư viện

Nhấn Win + R, gõ cmd, nhấn Enter rồi chạy lệnh:

py -3.13 -m pip install opencv-python numpy pyautogui mss keyboard

Hãy gõ lệnh trong Command Prompt (hiện C:\>), không phải trong Python hay IDLE (hiện >>>).

3Đặt script vào một thư mục

Lưu fishing_bot.py thành C:\fishing\fishing_bot.py. Mở thư mục đó, bấm vào thanh địa chỉ, gõ cmd rồi nhấn Enter. Dùng Command Prompt này cho mọi lệnh bên dưới.

4Chuẩn bị LDPlayer

Mở game ở màn hình câu cá. Sau đó không di chuyển hay đổi kích thước cửa sổ LDPlayer, vì bot ghi nhớ vị trí chính xác trên màn hình.

5Hiệu chỉnh (một lần)

py -3.13 fishing_bot.py calibrate

Với mỗi trong 5 câu hỏi, nhấn Enter, di chuột tới đúng chỗ và giữ yên đến khi đếm ngược 4 giây xong:

  1. Nút quăng cần xanh lá to.
  2. Nút lưỡi câu màu tím (quăng cần một lần trước để nút hiện).
  3. Đầu bên trái của thanh minigame (hãy bắt đầu minigame trước).
  4. Đầu bên phải của cùng thanh. Làm thật nhanh, minigame chỉ kéo dài khoảng 30 giây.
  5. Phần xanh lá của nút “Nhận Ngay”, không đặt vào chữ trắng. Dùng con cá không có minigame.

Làm lại riêng từng phần: calibrate bar, calibrate buttons hoặc calibrate claim.

6Đo thời gian cá cắn

Bấm giờ từ lúc quăng cần đến lúc cá cắn. Mở config.json bằng Notepad và thêm số của bạn, thấp hơn số đo được một chút:

"wait_after_cast": 7.8,

7Chạy bot

py -3.13 fishing_bot.py

Bạn có 5 giây để bấm vào cửa sổ LDPlayer. Hãy theo dõi vài con cá đầu tiên. F8 để tạm dừng hoặc tiếp tục, F9 để thoát, đưa chuột vào góc trên bên trái màn hình cũng sẽ dừng bot.

Cài đặt trong config.json

reward_screen_delay (1.5)
Số giây chờ trước khi đóng màn hình phần thưởng sau minigame. Tăng lên nếu bot bấm quá sớm.
latency (0.06)
Bot bấm sớm bao nhiêu. Tăng nếu bấm bị trễ, giảm nếu bấm bị sớm.
zone_margin (0.25)
Phao phải gần giữa vùng vàng đến mức nào. Số càng cao bot càng kén.
tap_cooldown (0.45)
Số giây chờ sau mỗi lần bấm trước khi đọc vùng vàng mới.

Khắc phục sự cố

“No config.json found”
Hãy chạy lệnh calibrate trước.
“No module named …”
Chưa cài thư viện, hoặc bạn gõ nhầm cửa sổ. Làm lại bước 2.
“Region has zero or negative size”
Hai đầu thanh bị lưu ngược thứ tự. Chạy calibrate bar.
Bot không nhận ra minigame
Bắt đầu một minigame rồi chạy py -3.13 fishing_bot.py debug. Nếu hiện bobber=None, hãy hiệu chỉnh lại thanh.
Màu bị đen hoặc sai
Trong cài đặt LDPlayer, đổi bộ kết xuất đồ họa giữa DirectX và OpenGL.
Bot bấm sai chỗ
Cửa sổ đã bị di chuyển hoặc đổi kích thước. Đặt lại như cũ hoặc hiệu chỉnh lại.

Bot dùng chuột thật của bạn, nên bạn không thể dùng máy cho việc khác khi bot đang chạy. Giữ cửa sổ LDPlayer hiển thị đầy đủ. Dùng bot hoặc macro có thể vi phạm quy định của game và ảnh hưởng đến tài khoản, hãy tự chịu trách nhiệm khi sử dụng.
